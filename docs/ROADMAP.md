# Планы и запуск

## Где мы сейчас

Технически сервис работает: генерация, смета, правки, кабинет, шаринг, админка, платежи, импорт.  
Но **публичный запуск блокирует отсутствие реального каталога**: 100 демо-товаров, 0 URL.

## P0 — до публичного запуска

1. **Реальный каталог**
   - 1 стиль × 1–3 комнаты;
   - 20–50 реальных товаров с URL, ценой, картинкой, габаритами;
   - импорт через админку (URL/список) или CPA/фид.
2. **Style kit из реальных товаров**
   - закрепить товары в `style_products`;
   - собрать комплект в админке;
   - перегенерировать hero-референсы под реальный набор.
3. **Заказ**
   - `/go/:productId` уже есть;
   - проверить реальные URL и клики;
   - позже — партнёрские ссылки/CPA.
4. **QA**
   - 10–20 реальных фото: спальня/гостиная/кухня/санузел;
   - проверить геометрию, комнату, свет, декор, смету, ссылки.
5. **Эксплуатация**
   - бэкапы БД/файлов;
   - мониторинг и алерты;
   - поддержка/возвраты/чеки;
   - проверить платежи живым платежом.

## P1 — качество генерации

1. **Двухстадийная генерация — база готова**
   - при выключенной мебели: очистка FLUX 3 Klein → дизайн FLUX 3 Image;
   - настройки в админке «Очистка»;
   - осталось решить биллинг: 2 кредита или 1, и сделать inpainting.
2. **Inpainting для света/розеток**
   - vision находит зону;
   - маска/локальная правка;
   - не полагаться на текст «повесь люстру».
3. **A/B моделей**
   - Seedream Flash vs Pro vs FLUX.2 Pro / Nano Banana 2;
   - 10 фото × 3 модели, слепая оценка;
   - выбрать по качеству/цене/стабильности.
4. **Upscale**
   - 1K/2K → финальный 4K.

## P2 — «Воплотить дизайн», каталог и партнёры

Полный план: [PROCUREMENT.md](PROCUREMENT.md).

1. **Качественный пилот с ограниченным охватом**
   - отдельный run для выбранного рендера, 5–8 hero-предметов и allowlist магазинов; Маркет исключён из-за SmartCaptcha;
   - подробная атрибутная карточка и crop;
   - 2–3 последовательных поисковых раунда с учётом причин неудачи;
   - проверка реальных карточек, visual score 80+, сохранение search rounds;
   - ранний выход, кэш, cost limits и feature flag; список товаров без сметы;
   - рефералка не используется; поисковая ссылка только для unresolved.
2. **Benchmark discovery providers**
   - 20–30 размеченных предметов;
   - Yandex Search API, модель с официальным web-search tool, официальные фиды;
   - сравнивать Top-1/Top-3 и стоимость принятого результата, не только цену запроса.
3. **Product Scout и фиды**
   - фид/allowlist → кандидаты → AI-разметка → score → approve;
   - CSV/XML, обновление цен/наличия, скрытие устаревших.
4. **Расширение покрытия**
   - 8–12 предметов, отделка, декор, комплектующие;
   - reverse image search для unresolved;
   - лимиты, кэш, cost/run и human acceptance.
5. **Партнёрские переходы**
   - canonical URL хранится отдельно, партнёр подключается на outbound;
   - Yandex Market CPA: `clid`/`place_id`, API ссылок/заказов, но не поиск;
   - subid на пользователя/рендер/item, клики, заказы, выплаты после подтверждения.

## P3 — продукт/маркетинг

- SEO/лендинг, кейсы до/после, соцдоказательства.
- Публичные страницы стилей/комплектов.
- PDF-смета с фото и товарами.
- Аналитика воронки: фото → генерация → правка → клик → покупка.
- A/B тарифов/пакетов.
- Мобильный редактор `/app` в новом стиле.

## Текущие ограничения

- Нет реальных URL → нет заказов.
- Нет автоматического выбора лучшего из 2–4 базовых вариантов и inpainting.
- Один основной провайдер.
- Нет автообновления цен/наличия.
- Нет автоматических бэкапов/метрик.
- FLUX.2 Pro: resolution не поддерживается + content moderation.
- Возвраты выключены, чеки вручную.

## Что нужно решить владельцу

1. Источник реального каталога: ручной импорт, фид, CPA.
2. 2 кредита за двухстадийку или 1.
3. Какие стили/комнаты первые.
4. Когда включать возвраты и автоматические чеки.

## Definition of launch

- 20+ реальных товаров с URL в одном стиле/комнате.
- Смета ведёт на реальные карточки.
- 10 успешных canary-генераций.
- Платежи и возврат кредита при ошибке проверены.
- Бэкап БД и файлов сделан.
- Поддержка отвечает на письма.
- Маркетинговая главная готова.
