# Админка

URL: `/admin`  
Доступ: заголовок `X-Admin-Key` = `ADMIN_KEY`; в браузере ключ хранится в `localStorage`. Ссылки в футере нет, `robots.txt` закрывает `/admin`.

## Вкладки

| Вкладка | Что делает |
|---|---|
| Пользователи | баланс, начисление/списание кредитов, ledger, история генераций |
| Пакеты кредитов | CRUD пакетов, цены, активность |
| Комнаты | справочник типов комнат: prompt, категории, слоты, keep/change, электрика, стилизация, активность |
| Стили | стили, prompt description, референсы, approve, товары стиля, генератор комплекта |
| Промт | редактируемые правила промта |
| Логи | фактические промты рендеров, модель, стоимость, референсы |
| Модели | render/vision модель, resolution/aspect, проверка input refs |
| Очистка | модель/промт/разрешение/aspect очистки комнаты, включение |
| Прокси | URL прокси, сохранение, health-check, маска пароля |
| Каталог | импорт по URL, массовый импорт, таблица товаров, цена/класс/статус |

## Комнаты

Справочник хранится в `app_settings.roomtypes.config.v1`, дефолты — `src/roomtypes.js`. Изменения применяются к новым генерациям без деплоя.

- **Название** — то, что видит пользователь; используется как ключ в старых комнатах, style references и товарах.
- **Prompt** — английское название комнаты для модели.
- **Категории** — какие товары допустимы; только из списка категорий каталога.
- **Слоты** — JSON-массив `{ key, categories }`, из него собирается смета. Категории слота должны входить в категории комнаты.
- **Keep / Change / Guidance / Forbid** — правила сохранения, замены, уместных предметов и запретов в промте.
- **Styling** — Pinterest-описание для финальной стилизации.
- **Электрика** — JSON-массив `{ title, text }` с рекомендациями по розеткам и свету.
- **Активен** — выключенный тип не показывается пользователям, но старые комнаты продолжают работать.
- **Сбросить всё** — возвращает заводские 12 типов.

Системный тип **«Другое»** удалить нельзя: он остаётся fallback для старых и неизвестных комнат. Должен остаться хотя бы один активный тип. Переименование не мигрирует старые данные, поэтому для вывода типа из использования лучше снять «активен».

## Промт

Правила хранятся в `app_settings.prompt.rules.v1`, дефолты — `src/promptconfig.js`.

Поля:

- **Свет** — cove, подсветка, лампы, запреты.
- **Размеры комнаты** — блок с `{room}`, `{width}`, `{length}`, `{height}`, `{orientation}`; добавляется, когда пользователь указал размеры.
- **План масштаба** — обёртка вокруг вычисленного плана мебели и проходов (`{room}`, `{plan}`).
- **Кровать** — блок с `{room}`, `{bed_length}`; используется только для спальни/детской, длина по умолчанию 2.0 м. Для гостиной, кухни и санузла блок не добавляется.
- **Радиаторы** — вентилируемые декоративные экраны; запрет выдумывать радиаторы и закрывать вентиляцию.
- **Уборка и техника** — радиатор, ТВ, провода, зеркала, люстры.
- **Окна и текстиль** — шторы, жалюзи, карнизы.
- **Pinterest-стайлинг** — арт, полки, техника, плюш, сцены.
- **Фотография** — камера, свет, плёнка, grading, запрет CGI.
- **Мебель: оставить / не учитывать.**
- **Каталог: включён / выключен.**
- **Дополнительно** — свободный текст в конец art direction.
- **Запреты** — негативный список.

Сохранение применяется к новым генерациям без деплоя. Старые рендеры не меняются. «Сбросить» возвращает дефолты.

## Стили

- Создание/редактирование стиля, ключ, название, prompt description, обложка.
- В миграции `027` добавлены неактивные стили 2026 (Ваби-саби, Органик модерн, Тёплый минимализм, Биофильный, Современная классика, Новый максимализм, Средиземноморский модерн); включаются здесь.
- **Референсы**: hero/board/upload, комната, score, approved. В генерацию идут только approved; hero — приоритет.
- **Товары стиля**: избранные товары, комната, sort.
- **Генератор комплекта**: комната + класс → товары только с URL → недостающие слоты → «Добавить всё в стиль».

## Очистка

- Работает только при `keep_furniture=false`; если мебель сохраняется — не применяется.
- По умолчанию включена, модель `black-forest-labs/flux-3-image-klein`, 1K, auto.
- Промт с плейсхолдерами `{room}`, `{keep}`, `{remove}`. Для кухни/санузла сохраняются встроенные элементы, сантехника и электрика.
- Пустой каркас хранится в `renders.shell_path` (`shells/`), удаляется вместе с комнатой.
- Очистка добавляет второй вызов модели; кредит пока 1.

## Модели

- Render-модель выбирается из image-моделей OpenRouter.
- Vision-модель — строка (обычно Gemini).
- Seedream: 1K/2K, aspect.
- FLUX 3 Image/Klein: 768/1K/1.5K/2K/4K, aspect.
- FLUX 3 Image Klein: 768/1K/1.5K/2K/4K, поддерживает resolution.
- FLUX.2 Pro: **resolution не отправляется**, поле «Задаётся моделью»; возможна блокировка content moderation.
- Gemini: resolution не отправляется, используется пропорция исходника.
- При сохранении проверяется доступность модели; warning пишется в лог.

## Прокси

- URL хранится в `app_settings.proxy.url`, применяется без рестарта.
- Health-check: `POST /api/admin/settings/proxy/test` (HTTP-код, мс, ошибка).
- Пароль маскируется в API/UI.
- Пустое значение отключает env-прокси.

## Каталог

- Импорт по URL: allowlist, JSON-LD/OpenGraph, качество, габариты, дубли.
- Массовый импорт до 20 URL.
- Таблица: поиск, цена, класс, комнаты, URL/клики, включение/выключение, удаление.
- Новые товары создаются черновиками (`active=false`).

## Безопасность

- Не храните `ADMIN_KEY` в репозитории.
- Не выводите пароль прокси в ответах.
- Импорт URL скачивает картинки только с публичных адресов (SSRF-защита).
- Проверяйте домены, allowlist и quality score перед включением товара.
