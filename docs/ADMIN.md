# Админка

URL: `/admin`  
Доступ: заголовок `X-Admin-Key` = `ADMIN_KEY`; в браузере ключ хранится в `localStorage`. Ссылки в футере нет, `robots.txt` закрывает `/admin`.

## Комнаты

Справочник в `app_settings.roomtypes.config.v1`, дефолты — `src/roomtypes.js` (12 типов). Изменения применяются к новым генерациям без деплоя.

- **Название** — ключ для старых комнат/референсов/товаров.
- **Prompt** — английское название для модели.
- **Категории/слоты** — допустимые товары и структура сметы.
- **Keep / Change / Guidance / Forbid** — правила промта.
- **Styling** — Pinterest-описание (в текущем промте не используется — известный баг).
- **Электрика** — рекомендации по розеткам/свету.
- **Активен** — выключенный тип скрыт у пользователей.
- **Сбросить всё** — 12 заводских типов. «Другое» удалить нельзя.

## Промт

Правила в `app_settings.prompt.rules.v1`, дефолты — `src/promptconfig.js`. Поля: свет, размеры, геометрия (`GEOMETRY LOCK`), план масштаба, кровать, радиаторы, уборка/техника, окна/текстиль, Pinterest, фотография, мебель, каталог, дополнительно, запреты.

**Известный баг:** `catalogOn`, `styling` не доходят до генерации; `furnitureOff` исправлен. Остальные правила применяются. Подробно — [docs/redesign](redesign/2026-11-11-redesign-codebase/redesign.md).

## Стили

- 10 канонических стилей (миграция `040`); неактивные скрыты.
- Референсы: hero/board/upload, комната, score, approved. В генерацию идут approved (при режиме `reference`).
- Товары стиля и генератор комплекта — для будущего каталога.
- Стиль и концепция выбираются парами в генераторе; см. `/api/design`.

## Очистка

- Только при `keep_furniture=false`.
- **Выключена по умолчанию**; модель `black-forest-labs/flux-3-image-klein`, 1K, auto.
- Промт с `{room}`, `{keep}`, `{remove}`; для кухни/санузла сохраняются встроенные элементы и сантехника.
- Очистка запускается асинхронно при первом enqueue комнаты; shell хранится в `rooms.precleaned_shell_path`.
- Статус: `rooms.cleanup_status` (`processing/done/error`), стоимость — `rooms.cleanup_cost_usd`; до 3 попыток, lease-heartbeat.
- Для кастомных admin-стилей без статической hex-палитры direction работает в `facts_only`, акцент — общий.

## Модели

- Render — из image-моделей OpenRouter; edit — отдельная (пусто = render); vision — строка (Gemini).
- Seedream: 1K/2K; FLUX 3 Image/Klein: 768/1K/1.5K/2K/4K; FLUX 2 Pro — resolution не отправляется.
- При сохранении проверяется доступность; warning — в лог.

## Очередь и кэш (env, не в UI)

| Переменная | Значение |
|---|---|
| `WORKER_CONCURRENCY` | 1–8, по умолчанию 6 |
| `IMAGE_MIN_GAP_MS` | пауза между image-вызовами (админка «Генерация») |
| `PARSE_AUTO` | `1` — авто-разбор после раннего done; по умолчанию off |

## Безопасность

- `ADMIN_KEY` не хранить в git.
- Пароль прокси не выводить в ответах.
- Импорт URL — только публичные адреса (SSRF-защита).
- Проверять домены/allowlist/quality перед включением товара.
