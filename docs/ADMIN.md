# Админка

URL: `/admin`  
Доступ: заголовок `X-Admin-Key` = `ADMIN_KEY`; в браузере ключ хранится в `localStorage`. Ссылки в футере нет, `robots.txt` закрывает `/admin`.

## Вкладки

| Вкладка | Что делает |
|---|---|
| Пользователи | баланс, начисление/списание кредитов, ledger, история генераций |
| Пакеты кредитов | CRUD пакетов, цены, активность |
| Стили | стили, prompt description, референсы, approve, товары стиля, генератор комплекта |
| Промт | редактируемые правила промта |
| Логи | фактические промты рендеров, модель, стоимость, референсы |
| Модели | render/vision модель, resolution/aspect, проверка input refs |
| Прокси | URL прокси, сохранение, health-check, маска пароля |
| Каталог | импорт по URL, массовый импорт, таблица товаров, цена/класс/статус |

## Промт

Правила хранятся в `app_settings.prompt.rules.v1`, дефолты — `src/promptconfig.js`.

Поля:

- **Свет** — cove, подсветка, лампы, запреты.
- **Уборка и техника** — радиатор, ТВ, провода, зеркала, люстры.
- **Окна и текстиль** — шторы, жалюзи, карнизы.
- **Pinterest-стайлинг** — арт, полки, техника, плюш, сцены.
- **Фотография** — камера, свет, плёнка, grading, запрет CGI.
- **Мебель: оставить / не учитывать.**
- **Каталог: включён / выключен.**
- **Дополнительно** — свободный текст в конец art direction.
- **Запреты** — негативный список.

Сохранение применяется к новым генерациям без деплоя. Старые рендеры не меняются. «Сбросить» возвращает дефолты.

## Стили

- Создание/редактирование стиля, ключ, название, prompt description, обложка.
- **Референсы**: hero/board/upload, комната, score, approved. В генерацию идут только approved; hero — приоритет.
- **Товары стиля**: избранные товары, комната, sort.
- **Генератор комплекта**: комната + класс → товары только с URL → недостающие слоты → «Добавить всё в стиль».

## Модели

- Render-модель выбирается из image-моделей OpenRouter.
- Vision-модель — строка (обычно Gemini).
- Seedream: 1K/2K, aspect.
- FLUX.2 Pro: **resolution не отправляется**, поле «Задаётся моделью»; возможна блокировка content moderation.
- Gemini: resolution не отправляется, используется пропорция исходника.
- При сохранении проверяется доступность модели; warning пишется в лог.

## Прокси

- URL хранится в `app_settings.proxy.url`, применяется без рестарта.
- Health-check: `POST /api/admin/settings/proxy/test` (HTTP-код, мс, ошибка).
- Пароль маскируется в API/UI.
- Пустое значение отключает env-прокси.

## Каталог

- Импорт по URL: allowlist, JSON-LD/OpenGraph, качество, габариты, дубли.
- Массовый импорт до 20 URL.
- Таблица: поиск, цена, класс, комнаты, URL/клики, включение/выключение, удаление.
- Новые товары создаются черновиками (`active=false`).

## Безопасность

- Не храните `ADMIN_KEY` в репозитории.
- Не выводите пароль прокси в ответах.
- Импорт URL скачивает картинки только с публичных адресов (SSRF-защита).
- Проверяйте домены, allowlist и quality score перед включением товара.
