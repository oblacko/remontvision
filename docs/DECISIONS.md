# Решения (ADR-lite)

Короткие ответы на «почему так».

## ADR-001: класс материала вместо суммы бюджета

Сумма в рублях не управляла подбором: модель не умеет в неё «жить», а смета всё равно собиралась из товаров. Ввели `start|comfort|premium|atelier` на комнате и товаре. Сумма осталась справочно.

## ADR-002: curated-товары — источник истины

Для первого рендера смета строится из curated-товаров, которые мы реально просили нарисовать. Vision только добавляет недостающие категории и не подменяет выбранную инженерную доску на «похожий ламинат». Правка копирует смету родителя и заменяет только target.

## ADR-003: правила промта — в БД

`lighting`, `cleanup`, `window`, `pinterest`, `photo`, `furnitureOn/Off`, `catalogOn/Off`, `extra`, `avoid` вынесены в `app_settings.prompt.rules.v1` и админку. Деплой не нужен, можно крутить качество и откатывать. Дефолты — `src/promptconfig.js`.

## ADR-004: свои hero-референсы, а не Pinterest-скрейпинг

Hero-сцены генерируются из наших товаров, проходят vision-скор и approve. Это даёт контроль, отсутствие проблем с правами и консистентность с каталогом. Внешние референсы — только через разрешённые API/фиды.

## ADR-005: очистка + дизайн при выключенной мебели

Если `keep_furniture=false`, сначала идёт очистка FLUX 3 Image Klein до пустого каркаса, затем дизайн FLUX 3 Image. Это лучше убирает старые объекты. Очистка настраивается в админке и включена по умолчанию. При включённой мебели — один проход без очистки. Биллинг пока 1 кредит, хотя вызовов два.

## ADR-006: демо-каталог отделён от реального

100 демо-товаров нужны для проверки дизайна, стилей и сметы. Реальные заказы невозможны, пока у товаров нет URL. Импорт по URL создаёт черновики, включение — вручную.

## ADR-007: модель выбирается в админке, FLUX 2 Pro — осторожно

Текущая модель дизайна — FLUX 3 Image, очистки — FLUX 3 Image Klein. Seedream остаётся дешёвым фолбэком. FLUX.2 Pro не принимает `resolution`, возможна content moderation на спальнях; не делать основным без QA.

## ADR-008: прокси управляется из админки

OpenRouter WAF может блокировать IP VPS. Прокси хранится в `app_settings`, применяется без рестарта, есть health-check. Пароль маскируется в API/UI.

## ADR-009: публичный шаринг без сметы

`/s/:token` показывает только визуализацию, стиль, комнату, лайки и комментарии. Фото комнаты и смета не публикуются. Токен случайный, `noindex`.

## ADR-010: смета и заказ через `/go`

Ссылки из сметы идут через `/go/:productId?r=renderId`: лог клика + 302 на URL товара или поиск. Это база для партнёрских ссылок и аналитики.

## ADR-011: габариты товара в промте

`products.dimensions` передаются в промт как физический масштаб. Модель не измеряет, но не должна превращать диван 220 см в кресло. Для мебели без габаритов — предупреждение при импорте.
