# Design Session v2 — быстрые правки и поиск через MCP

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Убрать визуальный мусор из результата, перенести подсказки архитектора в форму точечной правки и заменить автоматический/старый поиск товаров на MCP-агента по кнопке.

**Architecture:** Архитектор после рендера сохраняет `items` + `layers` в `renders.analysis`, но UI показывает только компактные быстрые правки внутри формы редактирования. Поиск товаров запускается кнопкой и вызывает `/vision-agent` в catalog-service: агент смотрит на рендер, использует MCP-инструменты каталога и возвращает реальные `offer_id`.

**Tech Stack:** React 19 + TS, Node ESM, FastAPI catalog-service, существующие `catalog_tools`/`vision_agent`.

## Решения

- Поиск — по кнопке, отдельного кредита нет: входит в кредит генерации.
- Хардкод `refinePresets` удалить.
- MCP — через HTTP `/vision-agent` в catalog-service.
- В форме правки — до 4 референсов.
