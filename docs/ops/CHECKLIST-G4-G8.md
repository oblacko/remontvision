## Что нужно от владельца

1. **Внешнее хранилище** для бэкапов: Yandex Object Storage (рекомендуется), другой
   сервер или S3. Нужны bucket/endpoint + ключ с правами только на bucket.
2. **Канал алертов**: Telegram-бот (token + chat_id) или e-mail получателя. Для
   внешнего монитора — аккаунт Better Stack/UptimeRobot (или согласие на GitHub-fallback).
3. **Разрешение на изменения прода**: установить `rclone`, скопировать скрипты в
   `/root/remontvision/scripts/ops/`, добавить 3 строки в root-crontab, включить logrotate.
   Это не деплой и не меняет БД/`.env`.
4. **Окно 10 минут** для теста G8: остановить `app`, получить алерт, поднять обратно.
5. **Диск**: 86% занято. Расширить диск/том или согласовать очистку (старые образы,
   логи, лишние копии). Иначе ежедневные полные бэкапы рискованны.
6. **`.env`**: положить актуальную копию в менеджер паролей/зашифрованный архив.

После выполнения п.1–6: включить cron, провести тест, заполнить таблицы, приложить
скрин алерта и `restore-verify` отчёт — тогда G4/G8 можно подписывать.
