## Блокировки

1. **Оферта ≠ факт**: `/offer` содержит старые пакеты (2/99 ₽, 5/229 ₽), «ЮKassa», «30–60 секунд»; фактически 8/399, 15/599, 50/1499 ₽, Robokassa, 1–4 мин. Открыто с 11-07 (F-11). Нужно решение владельца + юридическая проверка.
2. **«Реальные товары и смета» ≠ демо-каталог**: лендинг и meta обещают реальные товары; каталог — 100 демо-товаров, 0 URL. Hoff-каталог (36 092 оффера) готов в `catalog-service/`, но не в пользовательском потоке. Нужно решение владельца.
3. **Нет бэкапов/мониторинга** — нельзя принимать деньги без восстановления данных.

## Решения от владельца

1. Каталог: подключить Hoff-каталог в смету сейчас или честные формулировки («подборка товаров») на время запуска?
2. Оферта: согласовать редакцию (8/399, 15/599, 50/1499 ₽, Robokassa, 1–4 мин)? Кто проверяет юридически?
3. Доступы: Метрика, Вебмастер, рекламные кабинеты, support@, SSH на VPS (бэкапы), кабинет Robokassa (тестовый режим).
4. Реклама: регион/сегмент, бюджет первого теста; применяется ли ограничение Hoff на контекстную рекламу?
5. Возвраты: автоматические или ручные? Кто отвечает за поддержку?
6. Отзывы/кейсы реальных пользователей для лендинга?
