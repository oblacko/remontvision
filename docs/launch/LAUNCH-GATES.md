# docs/launch/LAUNCH-GATES.md — Условия готовности к запуску

Проверяемые условия. Gate считается пройденным только после выполнения проверки с фиксацией результата (ссылка на протокол/скрин/команду). Никаких «на глаз».

## Gates к расширению теста (после первых данных)

- ≥1 реальная покупка с подтверждённой атрибуцией (utm → `purchase` сверено с БД).
- Стоимость первого покупателя в согласованных пределах (потолок — из экономики, не из воздуха).
- Доля неудачных генераций (`render_error` / все запуски) ниже согласованного порога за 7 дней.
- 0 обоснованных жалоб/споров на несоответствие обещаний.

## Условия остановки теста (стоп-критерии)

1. ≥2 подряд неудачных платежа (или отказ платёжного провайдера).
2. Доля `render_error` выше порога за 3 дня подряд.
3. Юридическая претензия или требование регулятора.
4. Жалобы пользователей на несоответствие обещаний (повторяющиеся, ≥2 за неделю).
5. CAC выше согласованного потолка при 0 покупок после согласованного объёма трафика.

При срабатывании стоп-критерия: остановка кампании, разбор причины, фиксация в AUDIT/BACKLOG, повторный запуск только после закрытия причины и повторного прохождения gates.
