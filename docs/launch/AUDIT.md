## 2. Фактическая воронка пользователя (как реализовано)

1. **Вход/понимание** — лендинг «Примерьте ремонт до покупок», 2 кредита бесплатно, CTA «Создать мой дизайн». Проверено: desktop/mobile без hscroll (TC-01/02 в `audit/test-cases.md`).
2. **Генератор до логина** — гейт только на генерации (F-05, исправлено 11-07), состояние панели сохраняется.
3. **Регистрация/вход** — e-mail + код из письма (OTP, Resend) или Яндекс ID OAuth (миграция 042, одноразовый state). 2 кредита новому. Проверено: валидации, согласия (TC-04…10). **Не проверено live**: письмо с кодом (нет ящика, TC-09 BLOCKED) и OAuth на проде.
4. **Загрузка фото** — JPG/PNG/WebP ≤15 МБ; EXIF/GPS удаляются (`docs/OPERATIONS.md:121`). Тип комнаты, стиль (8 активных), класс материалов, размеры (опционально), «Очистить комнату» (опционально).
5. **Генерация** — 1 кредит, списание атомарно при постановке в очередь (`src/payments.js:350-407`); статусы queued→…→done|error; время 1–4 мин (аудит: 66 с и 241 с); при ошибке кредит возвращается; image-вызовы сериализуются (`IMAGE_MIN_GAP_MS=10000`), 429 → до 4 ретраев (10/20/40 с); таймаут OpenRouter 120 с (`docs/OPERATIONS.md:30`).
6. **Результат** — рендер, авторский бриф, разбор («что подобрать», RAL, розетки), версии правок, скачивание, шаринг. Проверено end-to-end в двух аудитах.
7. **Подбор товаров** — «Найти товары» 1 кредит: vision → Yandex Search API → allowlist магазинов → список товаров **без количеств и сметы** (`docs/MEMORY.md:56-66`). Прокси-фикс (A-19) задеплоен; **живой прогон после фикса в документах не подтверждён**.
8. **Смета** — из демо-каталога, 0 реальных URL; ссылки `/go/:id` → поиск. **A-16 открыта.**
9. **Роадмап ремонта** — полный только у купивших кредиты; бесплатным — скелетон + CTA (HISTORY 11-07).
10. **Оплата** — кабинет → пакеты (8/399, 15/599, 50/1499 ₽) → Robokassa redirect → ResultURL (подпись) → кредиты идемпотентно → чек (Робочеки СМЗ, service/tax=none). Возвраты выключены, чеки/возвраты вручную. **Живой платёж не выполнялся никогда** (запрет правил аудитов).

**Подтверждённые разрывы:** «реальные товары и смета» ↔ демо-каталог (`Home.tsx:309`, `web/index.html:8`); «Бюджет до генерации» ↔ «класс материалов» (`Home.tsx:338`, ADR-001); оферта ↔ факт (`public/offer.html`).

## 4. Аналитика и экономика

### 4.1. Подключено

Яндекс.Метрика `114132104` (webvisor/clickmap/ecommerce) на `/` и `/app`; клиентские цели через `web/src/lib/analytics.ts`: `signup`, `login`, `generator_open`, `render_start`, `render_done`, `edit_request`, `buy_click`, `purchase`, `share`. `purchase` срабатывает после того, как баланс реально вырос (polling `/api/me` после возврата из Robokassa) — приемлемый прокси, но источник истины — БД.

**Нет:** серверных событий в Метрику; целей `render_error` и `product_click`; трекинга ошибок; подтверждённого доступа к кабинету Метрики.

### 4.2. Минимальный словарь событий

| Событие | Когда отправлять | Источник истины | Допустимые параметры | Проверка корректности |
|---|---|---|---|---|
| signup | новая сессия после входа | users.created_at | — | тест-аккаунт → цель в Метрике |
| generator_open | открытие генератора | клиент | — | консоль/Метрика |
| render_start | запуск генерации | клиент + renders.status=queued | style, room_type | цель + строка в БД |
| render_done | рендер завершён | клиент (TaskDock) + renders.status=done | room_id | совпадение с БД |
| render_error | сбой генерации | серверный лог `render_error` | — | **цель в Метрике отсутствует — добавить** |
| edit_request | запуск правки | клиент | target | цель + parent_render_id |
| buy_click | клик «купить пакет» | клиент | pack_id | цель |
| purchase | оплата подтверждена | **БД payments.status=succeeded** | pack_id | сверка клиентской цели с БД |
| product_click | переход `/go` | серверный лог (ADR-010) | product_id, render_id | **цель в Метрике отсутствует — добавить** |
| share | открытие шаринга | клиент | render_id | цель |

Нажатие кнопки (`render_start`, `buy_click`) ≠ успех (`render_done`, `purchase`) ≠ подтверждённая оплата (`payments.status=succeeded`). ПДн, фото, секреты, платёжные реквизиты в параметры не включать.
